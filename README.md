# VRM Motion Studio

ブラウザーで人型VRMのポーズとモーションを作るエディターです。

1. **VRMを読み込む**で手元のVRM 0.x / 1.0を選びます。練習用モデルでも始められます。
2. プレビュー上の点や**動かす部位**から関節を選び、色付きのリングをドラッグして回転させます。プレビュー右下で1軸に絞れます。Shift を押してからドラッグすると細かく回せます。ドラッグ中は Esc で取り消せます。X / Y / Z の角度はスライダーと数値欄でも調整できます。
3. **コマを追加**で今のポーズをコピーし、次のポーズに変えます。時刻を調整して**再生**すると、ポーズ間を補間します。
4. **手の形**で左右別のプリセットを適用し、左側の指の一覧から各関節を微調整できます。両手のまるとハートは腕と手首も調整します。**表情**では種類と強さをコマごとに指定できます。
5. **編集用JSONを保存**で編集を続けられるファイルを、**VRMAを書き出す**で対応ソフトに渡せるアニメーションを保存します。1コマでも静止ポーズを保存できます。**全ファイター分をZIPで保存**では、VRM BRAWLの各ファイターのVRMAと共通の編集用JSONをまとめて保存します。

VRM本体はブラウザー内で読み込み、保存ファイルには含めません。同じ見た目で編集を再開するときは、同じVRMを読み込んでください。VRMAには身体と指の関節回転、腰の上下、設定した表情が入ります。表情の表示はモデルが持つ表情に対応します。[VRM Animationの仕様](https://vrm.dev/vrma/)

タイムラインの **INMU KING サビ** から、約25秒のダンスを現在のモデルで再生できます。停止してコマを選ぶと、ポーズや時刻を編集できます。書き出しにはダンスの動きが入り、楽曲の音声は付属しません。[振り付けの参考動画](https://www.youtube.com/shorts/gTUXDOvgE6M)

## ローカルで起動

Node.js 22.12以降で `npm ci`、`npm run dev` を実行し、表示されたURLをブラウザーで開きます。ビルドは `npm run build`、テストは `npm test` です。

VRM BRAWLのファイターが増えた場合は、`node scripts/update-fighter-rigs.mjs ../vrm-brawl/public` で一括出力用の骨格データを更新します。
