# VRM Motion Studio

ブラウザーで人型VRMのポーズとモーションを作るエディターです。

1. **VRMを読み込む**で手元のVRM 0.x / 1.0を選びます。練習用モデルでも始められます。
2. プレビュー上の点や**動かす部位**から関節を選び、ドラッグまたはX / Y / Zのスライダーで角度を調整します。
3. **コマを追加**で今のポーズをコピーし、次のポーズに変えます。時刻を調整して**再生**すると、ポーズ間を補間します。
4. **編集用JSONを保存**で編集を続けられるファイルを、**VRMAを書き出す**で対応ソフトに渡せるアニメーションを保存します。1コマでも静止ポーズを保存できます。

VRM本体はブラウザー内で読み込み、保存ファイルには含めません。同じ見た目で編集を再開するときは、同じVRMを読み込んでください。VRMAに入る情報は身体の関節回転と腰の上下です。[VRM Animationの仕様](https://vrm.dev/vrma/)

## ローカルで起動

Node.js 22.12以降で `npm ci`、`npm run dev` を実行し、表示されたURLをブラウザーで開きます。ビルドは `npm run build`、テストは `npm test` です。
